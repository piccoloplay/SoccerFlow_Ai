SoccerFlaw_Ai is a 3D multiplayer quiz party game set on a football pitch.

How to play

You need a PC as the main screen (host) and up to 4 smartphones as controllers.
Open the game on the PC, create a room, and share the room name with the other players.
Each player opens the game on their phone and joins the room.
For every question, answer by "shooting" the ball at one of the 9 panels (3×3 grid): the one matching the correct answer.
Watch out for the goalkeeper: even if your answer is right, if it saves the shot, the point doesn't count!
Two modes: Turns (players answer one at a time) and Free4All (everyone at once — whoever answers correctly first wins).
Available versions

WebGL (browser): play instantly, nothing to install — but without the AI-trained goalkeeper.
macOS / Windows: download this version to also try the goalkeeper controlled by the neural network (Reinforcement Learning).
